# 💼 Bizness Hisobchi

> Your business finance assistant — no spreadsheets, no paperwork, no app to learn.

---

## 👋 What is Bizness Hisobchi?

Bizness Hisobchi is a Telegram-based finance assistant built for small and medium businesses. The moment money moves — a sale, an expense, a payment — just tell the bot. It handles the rest.

---

## ✨ How It Works

Speak or type, however you like:

### 📥 Logging Income & Expenses
```
sold for 1,200,000 today
spent 350k on logistics yesterday
```
Or send a **voice note** — supports **Uzbek, Russian, and English** 🎤

The bot records the amount, type, category, and date — then confirms what it saved so you can trust the numbers.

### 📊 Asking About Your Numbers
```
how much did we earn this week?
what did we spend on rent in March?
```

## 🛠 Commands

| Command | Description |
|---------|-------------|
| `/dashboard` | Open your personal dashboard |
| `/report` | Quick summary of this month |
| `/undo` | Delete the last entry |
| `/reset` | Reset your dashboard password |
| `/lang` | Change language |
| `/help` | Show help anytime |

## 🚀 Tech Stack

- **Next.js** — Dashboard frontend & API
- **Telegram Bot API** — Conversational interface
- **TypeScript** — Full-stack type safety
- **Voice recognition** — Uzbek, Russian, English support

## 📦 Getting Started

```bash

# Run development server

```
